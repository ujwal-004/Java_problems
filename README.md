# Java Problems

A collection of Java solutions organized by platform: **HackerRank**, **LeetCode**, and **Unstop**.

## Folder Organization

| Folder | Source | Description |
| --- | --- | --- |
| `hacker_rank/` | HackerRank | Standard Java challenge solutions |
| `leetcode/` | LeetCode | Algorithm and data structure problems |
| `unstop/` | Unstop | Competitive programming problems |

## How to Compile and Run

The online-judge source files may use independent class names (e.g. `Solution` for LeetCode, or custom class names for Unstop) and **must be compiled individually** — there is no single entry point.

### Windows (PowerShell)

```powershell
# Compile
javac leetcode/TwoSum.java

# Run (replace ClassName with the class name from the file)
java TwoSum
```

### macOS / Linux (Bash)

```bash
# Compile
javac leetcode/TwoSum.java

# Run
java TwoSum
```
